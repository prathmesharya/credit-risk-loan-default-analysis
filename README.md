# Credit Risk & Loan Default Analysis 🚧

**Status:** In progress

## Goal
Analyse a public loan dataset to understand which borrower factors drive loan default risk, and present the insights in an interactive dashboard.

## Planned Workflow
1. **Data cleaning & EDA** (Python: Pandas, Seaborn, Matplotlib)
2. **SQL analysis** (default rates segmented by income, loan amount, employment, credit history)
3. **Power BI dashboard** (key risk drivers and portfolio overview)
4. **Findings & recommendations** (written summary of insights)

## Tools
Python · SQL · Power BI · Jupyter Notebook

## Dataset
Public loan / credit risk dataset (Kaggle). Source link to be added.
